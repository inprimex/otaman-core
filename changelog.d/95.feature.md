Added the exact harness `pin` field (`runner.harnesses[].pin`) and `otaman_core.harness_registry` — the one authoritative read-point for the fleet's pinned harness version. `harness_pin`/`read_harness_registry`/`find_harness` read the pin (deploy provisioning installs from it, the doctor compares the installed version against it); an absent pin reads as unpinned (None), not an error. The reader never writes — the pin is human/canary-authored and derived here, never authored.
