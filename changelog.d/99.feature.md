Added the `HarnessBackend` seam and `otaman_core.llm_router` for opt-in LLM routing. `DefaultBackend` is the byte-identical native path (returned when no `router:` config is present); `LiteLLMProxyBackend` routes through an OpenAI-compatible proxy. An agent declaration may name a `route` (model family / target); `effective_route` is the single resolution point. `guard_route`/`route_leaves_tenant` supply the sensitivity-guard predicate the bridge dispatch enforces — a non-local route for local-only content is refused, naming the class and target.
