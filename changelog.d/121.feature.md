`Route` now has a canonical `id` property — the presentation-free telemetry route key (`family`, `/model` when named, `@local` when tenant-local; e.g. `anthropic/claude-opus-4`, `ollama/llama3@local`). It encodes every identity-bearing field including `local`, so the same family/model run tenant-local vs off-tenant stay distinct telemetry buckets. Callers pass `effective_route(...).id` to `record_critic_cost`, so the route key lives in one home instead of each call site inventing its own rendering.
