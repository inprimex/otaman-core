`registry_access` gains `load_register(..., missing_ok=True)` for the create-fresh case and `read_register_fast` — a fast (C-safe-loader) lossy, read-only load for display paths, since the round-trip `load_register` is ~700ms (`save_register` refuses a fast register, which has dropped comments). `apply_transition` now omits `old` from a transition when the field was absent, so a first-ever set no longer reads as a null previous value.
