`otaman_core.release_gate.cut_eligibility` computes a per-change release cut-eligibility verdict (eligible / tasks-outstanding / gate-unpassed, with counts) — the fourth consumer of the single-home filed-completes reader. A change is cut-eligible only when every implementation task is filed complete (bus filings, retraction-aware, not tasks.md ticks) and its verification gate has passed; the verdict names the nearest blocker so a release cut can fail naming the ineligible change.
