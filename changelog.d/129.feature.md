`platform.yaml` now accepts a top-level `ownership:` map — repo-or-folder key → owning agent name (e.g. `otaman-folder: plugin-agent`). This is the program-level ownership block the otaman-meta merge gate protects; declaring it in the schema (which is `additionalProperties: false` at the top level) lets the canon ownership block be committed without the merge gate's own schema check refusing it. Distinct from per-repo `repos[].owner`/`owner-paths`, which route work within a repo.
