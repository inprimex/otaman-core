`apply_transition` now emits the pinned A.5 transition shape: a `changes` list of `{field, old?, new}` (one entry per changed field, `old` omitted when the field was absent) superseding the flat single-field trio, and an optional structured `approval.hat`. The outcomes-registry schema validates both sub-shapes when present (and historical flat-trio rows, leniently). cli consumes this as the canonical transition shape (rac, spec `d439a5c`).
